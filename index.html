❓ 자주 묻는 질문 (FAQ)

작성한 메모가 외부 서버로 전송되거나 열람될 수 있나요?

절대 그렇지 않습니다. 본 서비스는 100% 클라이언트 브라우저 로컬 환경에서만 실행되며 백엔드 서버나 외부 전송 API가 전혀 존재하지 않습니다. 모든 데이터는 사용자의 기기 LocalStorage에만 보관됩니다.

작성 중인 글은 언제 어떻게 저장되나요?

타이핑을 입력하는 즉시 브라우저의 LocalStorage에 실시간 자동 저장됩니다. 실수로 브라우저 탭을 닫거나 컴퓨터가 꺼져도 동일한 브라우저로 재접속 시 작성 중이던 내용이 완벽하게 복원됩니다.

작성한 문서를 파일로 내보낼 수 있나요?

네, 하단의 '.md 다운로드' 버튼을 클릭하면 표준 마크다운(.md) 파일로 즉시 내 컴퓨터에 저장할 수 있습니다. 옵시디언(Obsidian), 노션(Notion), VS Code 등 모든 마크다운 호환 에디터에서 바로 열어볼 수 있습니다.

어떤 마크다운 문법이 지원되나요?

제목(#~######), 굵게, 기울임, 취소선, 인라인 코드, 코드 블록, 글머리 기호 목록, 번호 목록, 체크박스 할 일 목록, 인용구, 구분선, 안전한 하이퍼링크가 완벽 지원됩니다. 입력된 원본 HTML은 안전하게 이스케이프되어 XSS 보안 위험이 차단됩니다.

브라우저 캐시를 지우면 메모가 사라지나요?

브라우저 설정에서 쿠키 및 로컬 사이트 데이터를 삭제하면 저장된 메모가 초기화될 수 있습니다. 중요한 기획서나 문서는 정기적으로 '.md 다운로드' 버튼을 눌러 안전하게 백업해 두는 것을 권장합니다.
